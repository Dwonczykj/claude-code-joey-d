name: typescript-execution
description: How to run TypeScript files and scripts on this machine. Use when executing .ts files, running ts-node, or invoking the `tsn` alias.
---

`tsn` is a zsh alias for `ts-node` defined in ~/.zshrc. It won't resolve in non-interactive shells, so use `npx ts-node <file>` directly in the Bash tool.
